These structured responses were captured sequentially through the globally
registered headless MCP on 2026-09-12, using `type: weapon`. The corresponding
source is `tests/scripts/<relative path>`, with `//#CLIENTSIDE` prepended when
missing, unless a companion `.official.gs2` records an approved adjustment.
No expected bytecode is generated by the local compiler.

an older `modified_1767569912` compiler, not the current official oracle.
